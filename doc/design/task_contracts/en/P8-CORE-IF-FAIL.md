# Task P8-CORE-IF-FAIL: conditional and bare-failure shells
Canonical language: English; [Japanese pointer](../ja/P8-CORE-IF-FAIL.md).

- Status: frozen; blocked on resolver source-profile support; full tier. Primary owner: [Core plan](../../mizar-core/en/00.crate_plan.md#task-index), [Tasks 43/48](../../mizar-core/en/todo.md). Consumer: checker-authenticated source lowering; dependency P5 is available and checker serialization with P7 is released.
- Purpose: lower authentic source conditionals and bare failure into syntax-free Core/CFG, preserving branch conditions and failure's absence of normal continuation or postcondition.
- Authority: specification [20.2.1](../../../spec/en/20.algorithm_and_verification.md#2021-conditional-if), [20.2.6](../../../spec/en/20.algorithm_and_verification.md#2026-jump-statements-return-break-continue-fail), and [20.13.3](../../../spec/en/20.algorithm_and_verification.md#20133-verification-condition-schema); test-first [source fixture](../../../../tests/fixtures/core/p8_if_fail.miz), existing algorithm source and CFG tests.
- Prerequisite blocker: `SourceVariableScopeResolver::resolve_algorithm_occurrences` in `crates/mizar-resolve/src/names.rs` rejects If/Fail before checker inference. Existing alternate APIs do not provide authenticated algorithm bindings. Extending this lower-stage producer is outside the dispatched file scope; Muse must authorize that prerequisite before implementation resumes.
- Gaps: source checker/lowerer omit If/Fail; Core and CFG lack failure terminals; CFG false branches omit their condition and joins discard surviving conditions; value-result fallthrough currently becomes an implicit void return. These are bounded source/design drift, not new language intent.
- Scope: checker `type_checker.rs`, Core `core_ir.rs`, `elaborator.rs`, `control_flow.rs`, minimal exhaustive-consumer/refusal glue, existing Core and source-integration test modules, paired owner docs and task indexes. API/invariants: [lowering](../../mizar-core/en/elaborator.md#static-source-algorithm-lowering), [CFG construction](../../mizar-core/en/control_flow.md#core-to-cfg-construction), [diagnostics](../../mizar-core/en/control_flow.md#diagnostics).
- Internal design: reuse If seeds and actual checked equality or prefix-negated equality conditions. Admit nested if/else-if with return/bare-fail/if branch statements, including absent/empty branches; preserve existing flat and bounded-while profiles. Reuse binding inference and authenticate tokens, order, ranges, owners and operands. Bare fail is admitted only in nonterminating runtime source; unsupported payload/placement remains an internal source-profile refusal.
- Add explicit Fail seed, Core statement, CFG terminator and exit. No successor context or ensures site belongs to failure. Retain unreachable shells using existing diagnostics. Store false conditions as original formula IDs in `ProgramContext.negated_path_conditions`; join intersects both polarities over normal exits only, preserving a sole survivor. Value-result reachable fallthrough produces internal MissingReturnOrFail with an error terminal; void fallthrough keeps implicit return. No public E0501 or E0503 is emitted.
- Forbidden: specification changes, existing fixture rebaselines, public diagnostic codes, terminating/ghost failure admission, message/value fail, branch-local declarations or snapshots, loop-profile expansion, VM execution, conditional VC generation, proof/acceptance/promotion or snapshot baseline/coverage credit. VC consumers must refuse unsupported conditional/failure profiles. Coverage audit and trace activation remain unchanged; Tasks 43/48/53 remain partial.
- Test matrix (six cases, variants within each): (1) genuine fixture plus renamed/not-condition controls preserve Core formulas, bindings, nested statement/source ownership and deterministic CFG; (2) both terminal branches and nested else-if produce return/fail exits with no reachable continuation and ensures only on returns; (3) absent/empty else plus later return retains negative condition, mirrored surviving then retains positive condition, two normal exits discard branch-only conditions; (4) bare fail then unreachable return/assert retains diagnostics but no reachable postcondition or continuation, all-fail produces no return sites; (5) value-result empty/partial-if/loop-exit fallthrough yields internal MissingReturnOrFail, return/fail-complete paths do not, void fallthrough returns; (6) message/value fail, terminating/ghost fail, unsupported branch declarations, source/typed/environment mismatch and unknown condition operands refuse; existing VC source profiles refuse if/fail without proof credit.
- Reviews: independent specification/test-intent before freeze; test sufficiency, precision, volume/scope, final source/docs consistency and scoped quality after implementation.

Implementation adds fmt check, all-target/all-feature Clippy with denied warnings, checker/Core owner tests and focused real-source integration/E2E. Run affected VC refusal tests; unchanged proof/kernel, evidence/cache and receipt heavy matrices defer to integration. Full regression follows cadence; lane branch has no full-test trigger and no push.
- Exit: reviewed matrix and focused checks pass, source and paired owners agree, and freeze then implementation are committed on lane2/mvm. Muse owns integration and subsequent task selection.
