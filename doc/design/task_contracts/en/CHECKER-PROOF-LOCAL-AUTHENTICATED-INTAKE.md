Gap: `design_drift` with a soundness edge. The public Let, Given, Given-use, Given-condition and descendant build inputs accept freely supplied strings and ranges. Their dependency validators authenticate such an input only by comparing it with the canonical fixture's literal offsets (five dependency guards per form, three base-environment guards, two first-descendant guards: thirty constants, the last `source_proof_local_declaration.rs` row of `tests/coverage/literal_source_offset_baseline.tsv`). So production carries a fixture-specific branch, the public API admits exactly one source layout, and no generic row can replace a guard: a supplied range makes a coherent forged input pass, and decoding the lower fingerprint string would be a decoder oracle.
## Scope
One authenticated intake. The checker derives a receipt (theorem, proof, declaration, segment and name ranges; base reserved-declaration ranges; the first descendant range) from the installed generic source-node table of an authenticated `TypedAst`, the same table the native consumers read. The receipt is constructible only by checker code from that table, never from strings or from the candidate's own fields. Public build and installation replay take the receipt and the validators compare the supplied input with it instead of with literal constants, keeping every refusal class and its order. The runner's five build sites and replay sites pass the receipt they obtain from the same table. Then the thirty constants and the baseline row are deleted; a lower-fingerprint profile that the receipt makes redundant is deleted with them.
Affected: `crates/mizar-checker/src/source_proof_local_declaration.rs` (one receipt type or one changed input field, no second constructor), the runner's `source_statement.rs` and `source_proof_local_declaration.rs` consumers, the owner document's public API section (boundary change), the baseline ledger.
## Forbidden
Self-replay authentication (a receipt built from the candidate's fields or lower debug text); a fallback that still admits an unauthenticated input; a second constructor or mutable handoff access; activating deferred semantics (condition facts, proof obligations, `set` expansion); changing `doc/spec`, `.miz`, expectations, trace status, or coverage credit.
## Verification and exit
Existing owner tests for the five forms pass unchanged except where they supplied a literal expectation, which now comes from the receipt; the existing corruption tests show that a coherent forged receipt/candidate pair and a receipt from a foreign table are refused with the existing error classes; runner build and replay pass on the frozen inputs; metamorphic layout variants pass. Reviews: specification, test-sufficiency, implementation, volume/scope, consistency. `cargo fmt --check`; Clippy per `AGENTS.md`; full `cargo test` at exit. Exit: `source_proof_local_declaration.rs` compares no literal source offset and its baseline row is gone; the owner document's public API section states the receipt and its origin; the proof-local carve-out in VELOCITY-GENERIC-SOURCE-TRANSPORT is deleted.
