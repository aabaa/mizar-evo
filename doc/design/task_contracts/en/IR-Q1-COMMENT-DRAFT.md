## Bound Draft Contract
Add `project_commented_module` on ArtifactProjectionService with ordinary projection input, Session SnapshotRegistry, typed sealed FrontendOutput<SurfaceAst>, genuine immutable CommentMetadata and an ordered optional export-target pair per metadata landmark. Return a CommentedArtifactDraft retaining snapshot, required-output ids, existing external gaps and one Artifact-owned CommentedArtifact. No duplicated payload.
Fetch the registered snapshot by input id; validate unique full SourceVersion against the readable sealed payload: SourceId, package, module, normalized path, source hash, edition and genuine Disk/OpenBuffer origin/version. Retain input package-version/module lockfile identity; compare artifact package/module/path/edition/hash and captured-source tuple exactly, plus snapshot lockfile/toolchain/verifier hashes. No basename/prefix/range/lexical-hash binding. Metadata must match the actual payload's source, original/loaded/lexical frames, loading/preprocess maps, token/AST structure and landmarks. Frontend may expose a boolean canonical-payload binding check with private immutable evidence; unsupported canonical representations refuse projection. No metadata constructor.
Require the Frontend output itself among required outputs, phase Frontend, kind FrontendOutput and current schema. Validate exact publication roots, physical readability and currentness before and after conversion. Every other required output must transitively descend from that Frontend output through registered current-snapshot lineage; missing/foreign/unrelated ancestry refuses the draft. Verified records retain their existing projection boundary.
Convert metadata losslessly to the codec shape: original/loaded/lexical text, loading/preprocess segments including synthetic anchors, raw comments, whitespace and ordered landmarks with parent/recovery data. Validate the complete enclosing normal1.2 artifact and comment envelope through Artifact's codec before returning. Invalid identity, maps, frames, target shape or producer binding yields an error and no partial or unavailable fallback. No runtime handles enter comments.
Targets are optional `(origin_id, fully_qualified_name)` pairs for enclosing exports; never infer association. Missing/conflicting association remains null for Doc, while a supplied nonmatching export pair or wrong target-vector length is an integrity refusal. Preserve unresolved landmarks and text.

## Test Matrix And Exit
Six Rust cases (cap six):
1. Genuine Disk metadata plus sealed readable Frontend and descendant verified outputs: complete codec-valid unpublished draft, explicit export target and unresolved landmarks retained, full enclosing identity preserved.
2. OpenBuffer/version, BOM/CRLF, Unicode/empty doc/ordinary comments, annotation/wrapper/recovery landmarks and synthetic maps: lossless complete frames/maps with no package-publication upgrade.
3. Available-empty versus empty doc line, comment-only source edit with lexical reuse, equivalent captures/input enumeration: correct availability, implementation/full hash changes and deterministic bytes.
4. Metadata versus actual sealed payload substitutions (source, maps, token/AST structure), forged snapshot contents/foreign source identity, package/module/path/edition/origin/version/hash/provenance mismatch: no draft.
5. Obsolete/foreign snapshot, missing/unpublished/unreadable/collected output, duplicate required output and unrelated/missing ancestry: lower-owner refusal, no partial output or sealed mutation.
6. Wrong target-vector length/nonmatching pair, unresolved targets, codec map/bounds rejection, raw-data leakage and legacy projection compatibility: fail closed or preserve unresolved evidence as appropriate.
Independent specification, sufficiency, precision, volume/scope and final source/document consistency reviews; full task-scoped gates. No spec-coverage audit status/ownership changes.
