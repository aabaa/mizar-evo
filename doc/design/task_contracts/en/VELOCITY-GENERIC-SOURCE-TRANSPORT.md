This dominated the week ending 2026-11-02 without moving the roadmap.
## Scope
1. Design (docs-only commit): inventory the syntax elements and witness/layout forms of Tasks 257-279 that still lack original-source transport. Classify each as (a) derivable by a generic walk over the authenticated frontend tree, (b) needing an element-specific rule, or (c) semantic and deferred. Record the result in the source statement design document and freeze the generic producer's input/output contract and its refusal conditions. Classification ledger: `tests/coverage/source_transport_classification.tsv`.
2. Generic producer: one crate-private walk over the authenticated `TypedAst`/frontend handoff that derives sites, ranges, parents, and ordering for every (a) element from the actual tree, replacing the per-element `from_original`-style constructors. Element-specific rules (b) plug into the walk and do not duplicate it.
3. Generic oracle: tests compare producer output with the frontend's own spans and structure for every active corpus case (Root-reachable shape, documented recovery anchors, ordering, and metamorphic layout variants; unrecoverable frontend absence retains its diagnostics), replacing literal-offset profiles. Retire the `exact_*_profile` functions and lower `tests/coverage/literal_source_offset_baseline.tsv` to zero for the affected modules.
4. Unit of work: a remaining (b) element is one pattern-tier slice under one family contract; the lower/pair/preservation triple is no longer the unit.
## Family slices
Ledger: `tests/coverage/source_transport_migration.tsv` holds one row per slice (slice, family, predecessor, status, note). A slice is complete when its row is `done`; no slice adds a contract line. Default predecessor: the completed initial shared native statement consumer, whose authenticated table and oracle pattern every slice repeats unless its row names another.
Families and exit criteria:
- statement/witness: exact profiles and `literal_source_offset_baseline.tsv` rows of `source_statement.rs` retired (exit criterion 3)
- proof-local declarations (Task 269): the same for `source_proof_local_declaration.rs`, except the thirty canonical dependency, base and first-descendant guards of the public Let/Given/Given-use/Given-condition/descendant build inputs and their baseline row, which [CHECKER-PROOF-LOCAL-AUTHENTICATED-INTAKE](./CHECKER-PROOF-LOCAL-AUTHENTICATED-INTAKE.md) retires: a supplied range cannot replace a guard, and decoding the lower fingerprint is a forbidden oracle

- type, term and formula: native TYPE and direct B1 read the generic table under the accepted-input boundary in the [source statement design](../../mizar-checker/en/source_statement.md#generic-original-source-transport-task-284-design); the mode, predicate and attribute definition runners lose their literal offsets, where a deliberate corruption control that constructs a stale or underflowing range is either moved under `cfg(test)` or recorded in its ledger row as a retained production self-check, and either closes the row
- class `b` element rules: moved to [VELOCITY-ELEMENT-RULE-TRANSPORT](./VELOCITY-ELEMENT-RULE-TRANSPORT.md) and its ledger; not an exit condition of this task
## Forbidden
Fabricating sites or ranges absent from the frontend tree; widening admitted semantics; changing `doc/spec`, `.miz`, expectations, trace status, or coverage credit; keeping a fixture-specific branch in production code; adding a parallel AST or span representation where an existing one can be referenced.
