## Exact Portable Contract
Add `comment_projection::CommentedArtifact { artifact: VerifiedArtifact, comments: CanonicalJson }`, using existing errors/read-options. Expose `commented_artifact_json`, `write_commented_artifact`, `read_commented_artifact`, and methods computing interface/implementation/full hashes. Read-options expected hashes mean envelope hashes (clear them for nested validation); expected module binds the nested artifact. Both reader and writer validate completely; no partial result or profile retry.
Independent family `mizar-artifact/commented-verified-artifact`, exact version `1.0`. Canonical envelope fields: `schema_version`, `artifact` (required validated normal1.2), `comments`, `interface_hash`, `implementation_hash`. Hash strings use existing framed-hash encoding with this family/version/class. Required fields and tuple arities are exact; unknown/missing fields, unsupported versions/types fail.
`comments:null` means unavailable; otherwise an object with exactly `original`, `loaded`, `lexical` (UTF8 strings), `loading`, `preprocess`, `comments`, `whitespace`, `landmarks` (arrays). Empty arrays with complete frames mean available-empty. Identity/package-version/path/edition/origin/source-hash inherit the validated artifact; source hash equals hash_text(loaded), editions agree. Frame lengths are UTF8 byte lengths of retained strings; ranges below are `[start,end]` half-open byte offsets, integer, bounded and UTF8-aligned.
Loading tuples: `["original"|"newline", loaded_range, original_range]`, `["bom",null,original_range]`; require exact Session normalization and complete ordered segments. Preprocess tuples: `["original",lexical_range,loaded_range,null]`, `["removed",null,loaded_range,comment_kind]`, `["synthetic",lexical_range,loaded_anchor_range,null]`. Original slices agree; original/removed ranges cover loaded text once, lexical ranges cover lexical text once; synthetic whitespace anchors remain distinct and lie inside removed comments. No generated/exact substitution.
Comment tuples `[kind,loaded_range,raw]`, kinds `single_line|multi_line|documentation`, preserve markers/empty bodies, match slices and removed segments one-to-one. Whitespace ranges are ordered nonoverlapping whitespace outside comments. Landmarks `[kind,loaded_range,parent_index|null,recovered_boolean,target|null]` use nonempty symbolic syntax kinds, source order `(start,-end)`, preceding containing parents; target `[origin_id,fully_qualified_name]` must match one enclosing export. Unresolved targets stay null. Reject duplicate `(kind,range,parent)` landmarks; equal ranges across different landmarks/anchors remain legal. Arrays retain source/segment order; reject inconsistent order, duplicates, bounds, maps and bindings without downgrading availability.
Interface input is existing `interface_hash_input_json` with `schema_version` replaced by `"1.0"`. Implementation input is exactly `{"schema_version":"1.0","artifact":implementation_hash_input_json(artifact),"comments":comments}`. Hash domains use the envelope family/version and existing Interface/Implementation/Artifact classes; strings use `ArtifactHashRef::to_artifact_hash_string`. Full hash covers canonical envelope. Prefix existing local exclusions with `artifact`; never exclude comments. No circular publication hash.
