## Scope
One element rule per class `b` kind: a crate-private function that reads the kind's rows from the installed generic table and the resolver's roles and clocks, and yields the role-tagged sites the owning task's producer consumes. The rule plugs into the walk's output; it does not re-walk the tree, re-derive ranges, or carry fixture-specific branches. The owning producer reads roles only from the rule.
Row navigation: rules read the table through one crate-private helper set beside `SourceNode` in `typed_ast.rs` (children of a parent, the unique child of a kind with containment and ordering checks, the child at an ordinal, contiguous child count); a rule does not restate these filters. The definition rules written before this sentence (2026-11-04) move onto the helpers as one light-tier slice, ledger row `row-navigation-helpers`, before the next definition rule.
Intake shape: the original-`TypedAst` intake fixed by the definition family's first rules (one optional `TypedAst` argument on the existing build, one retained generic table in the handoff, re-validation at build, typed installation and resolved replay) is the reviewed shape. Adding it to another producer is a pattern slice, not a new public seam, unless the producer's refusal classes or its public input types change.
Families (classification `family` column) and owning tasks: `definition` (Tasks 279/270; 13 kinds), `proof-skeleton` (Tasks 272/269; 12 kinds), `reconsider` (Task 271; 3 kinds), `expression` (Task 257; 2 kinds).
Retained constants inherited from VELOCITY-GENERIC-SOURCE-TRANSPORT (its `element-rules` and `type-term-formula-exit` ledger rows): the `definition` family retires the functor declaration-eligibility constants of `source_functor_definition.rs` and the resolver-origin, admission and prefix-geometry constants of `source_property_implementation.rs`, since a rule supplies the roles they stand for; the `expression` family decides each nested-Fraenkel and condition-aggregate constant of `source_term.rs` and `source_formula_composition.rs`: retire it by a rule, or record it as class `c` in the classification ledger with the task that defers it. The proof-local constants of `source_type.rs` and `source_term.rs` belong to [CHECKER-PROOF-LOCAL-AUTHENTICATED-INTAKE](./CHECKER-PROOF-LOCAL-AUTHENTICATED-INTAKE.md).
