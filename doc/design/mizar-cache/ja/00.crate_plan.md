# Crate Plan: mizar-cache

> 正本は英語です。英語版: [../en/00.crate_plan.md](../en/00.crate_plan.md)。

## 責務

所有する挙動:

- 正規化済みの identity、hash、schema version、verifier policy 入力から正準的な cache key を構築する。
- producer crate が安定した入力を公開した後で、dependency fingerprint、dependency slice、保守的な rebuild trigger を計算し検証する。
- `cache_dir` 配下に内部 cache record と content-addressed blob を保存する。
- accepted proof witness hash または deterministic discharge hash に対して proof-reuse record を検証する。ただし proof authority は与えない。
- 検証済み registration / cluster contribution のために、`cluster-db/` index、origin metadata、import-scoped view を維持する。
- すべての cache hit を clean build 挙動に対する最適化として扱い、欠落、不完全、非対応、または信頼できない data では miss に退化する。

対象外:

- proof authority、kernel acceptance、certificate checking、proof search、proof-witness selection、外部認証された evidence の kernel-verified status への昇格。
- VC、`ObligationAnchor`、canonical VC fingerprint、local-context fingerprint、accepted proof witness の生成。
- build scheduling、task invalidation graph の所有、IR storage handle、artifact publication、manifest authority。
- language syntax、static semantics、proof semantics、diagnostics、既存 `.miz` test、既存 expectation、`doc/spec` の変更。

## Exit criteria

task 1 の hard gate:

- crate scaffold が task 1 と一致し、後続 behavior を実装していない。
- 既知 gap が `test_gap`、`spec_gap`、`design_drift`、`external_dependency_gap` として分類され、deferred action がある。
- design/source doc が task 1 scope と module 名について一致している。
- boundary discipline が保たれている。cache は proof authority ではなく最適化である。
- 必要な verification command が通るか、未実行なら明示的な理由がある。
- review-only agent が unresolved blocking/high finding なしを報告する。

crate 全体完了の hard gate:

- すべての module spec が、対応する implementation task より前に英日で存在する。
- spec と test にない source behavior が残っていない。
- cache hit は fail-closed であり、clean-build equivalent である。
- reuse には complete dependency slice / footprint が必要である。
- proof reuse は必要な evidence をすべて検証し、外部認証された evidence を決して昇格しない。
- `cluster-db` は accepted importer-visible contribution だけを含む。
- source、test、bilingual doc が同期している。
- 必要な verification command が通る。
- read-only review が有効な quality score 90/100 以上を付ける。

Verification commands:

```sh
cargo test -p mizar-cache
cargo clippy -p mizar-cache --all-targets -- -D warnings
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
```

Review expectations:

- implementation 前の implementation-spec / design review。
- test 追加後の test sufficiency review。
- code change 後の full implementation review。
- verification 前の source/documentation consistency review。
- 推奨 reasoning setting 付きの次 task handoff prompt。
