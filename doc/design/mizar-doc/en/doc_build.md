## Published Export Metadata
`read_published_export_index(artifact_root: impl AsRef<Path>, expected_manifest_hash: Hash) -> Result<(PublishedManifestRead, BTreeMap<ModuleSummaryIdentity, Vec<VerifiedExport>>), ManifestError>` supplies raw published metadata for later build/index planning, using existing types only.
Call the existing [published reader](./artifact_reader.md#published-input-loading) with the required expected publication hash; retain its complete manifest/path/hash unchanged and propagate its existing validation/error layers without partial results. Add no read, codec, hash domain, cache, callback or production helper.
Move each complete VerifiedExport into the map under its full original ModuleSummaryIdentity. Use that existing Ord (package id, optional version, optional lock identity, module path, edition), not module path alone or parsed version order. Existing Manifest validation guarantees unique full module keys; keep modules with empty exports.
Within each module, sort by stored fully_qualified_name then origin_id using exact string order. Artifact's original origin-first order is different; its per-module origin uniqueness makes this a total order. Preserve duplicate FQNs, Public/Reexported visibility and every typed field/optional value; do not deduplicate, select a winner, parse names/signatures, derive labels or synthesize absent metadata.
An outer Manifest package is not independently equated to each entry's package tuple. Preserve those stored identities without inventing owning-package equality, source provenance, currentness, acceptance or link-resolution authority. Stored projected proof statuses remain data.
Three appended source-backed structural families cover normal/explicit metadata and FQN ordering, full identity collisions/duplicate FQNs/absent options, and empty modules plus delegated refusal/byte preservation. Reuse the genuine published-reader fixture and unchanged lower matrices; any private shared publisher needs three real family callers.
## Optional Published Module Summaries
`read_published_module_summary_index(artifact_root: impl AsRef<Path>, expected_manifest_hash: Hash) -> Result<(PublishedManifestRead, BTreeMap<ModuleSummaryIdentity, Option<ModuleSummary>>), ManifestError>` exposes existing typed sidecars for later label/index consumers, using no new representation.
First call the existing published-artifact reader with the required expected hash; preserve its entire manifest/path/hash and propagate every original refusal without partial results. Its reference validation owns complete optional triples, schema/source/module/interface binding and witness reachability.
For each present module-summary triple, reload its original portable path through existing PublishedArtifactPath/read_published_artifact with MODULE_SUMMARY_SCHEMA_FAMILY, the declared schema version, no exclusions and the declared expected store digest. Decode with existing read_module_summary and actual expected module/interface hash. Preserve StoreIo and ModuleSummary { path, boxed error } layers. The same complete-content hash retains the first pass's schema/source binding; do not copy private validation or add another codec/helper/domain/cache.
Return every manifest module under full existing ModuleSummaryIdentity Ord, including None when the optional triple is absent and Some with empty labels when an empty summary is present. Preserve every typed summary field and original vector order exactly; never infer a label from FQN/signature, join labels to exports, deduplicate collisions or discard other summary metadata.
Three appended source-backed structural families freeze complete typed preservation/replay and read-only bytes; full-identity distinctions plus absent/empty summaries/modules; representative delegated hash/path/module/interface/source refusals. Reuse original genuine published-artifact fixtures and lower validation matrices. Any appended private fixture helper must have three real family callers; stored structural label records remain caller-owned metadata, never fabricated producer/acceptance evidence.
This is published-data integrity only: neither source/package/current-workspace authentication nor proof acceptance, link resolution, source adjacency, trusted reuse or complete DocIndex/rendering. Full label association/collision/page/anchor/import-order policy and later integration stay open.
## Published Label Export Candidates
`read_published_label_export_candidates(artifact_root: impl AsRef<Path>, expected_manifest_hash: Hash, module: &ModuleSummaryIdentity, label: &ExportedLabelSummary) -> Result<(PublishedManifestRead, Option<Vec<VerifiedExport>>), ManifestError>` queries stored owner candidates for one actual published label record, using existing types only.
First call read_published_export_index, then read_published_module_summary_index with the same root and required expected publication hash; complete validation and original errors precede lookup even for absent/forged query records. Preserve the first complete manifest/path/hash, return no partial result, and add no read/codec/hash/default/cache/helper or lower-stage change. Both readers' validated complete module sets belong to that selected publication.
Require the same full ModuleSummaryIdentity and equality of every field of an original exported_labels record to the supplied label. Missing module, absent summary, empty labels or no exact record returns None. This record query does not distinguish those absent-record causes; the existing summary reader retains their complete metadata.
For an actual record, return Some with all and only that module's exports whose stored fully_qualified_name equals its stored owner_fully_qualified_name. Keep complete original exports in existing FQN/origin order; no matching owner yields Some(empty), and duplicate owner FQNs yield all candidates. Never join across module identities, choose a winner, deduplicate repeated labels/exports, derive labels from names/signatures, or infer export origin/range/kind/visibility from label fields.
One appended production function only; retain all old Rust/Cargo/fixture/expectation/trace/ledger bytes. Append exactly two doc_label_export_candidates_* structural-publication test families without a new helper, reusing existing Doc publication fixtures and Artifact writers. Cover unique/multiple/unmatched candidates and full typed fields/order/replay/read-only bytes; identical module paths with distinct full identities, repeated label text, whole-record forgeries, absent-record cases and representative original error layers before lookup. Reuse lower validation coverage instead of repeating whole matrices.
These are exact stored metadata candidates, not resolved visible references, anchors/pages/links, warnings, source attachment, semantic export production or a complete DocIndex. Stored proof status stays data; source/package/current-workspace/acceptance/witness/reuse/cache authority, import-order/dependency indexes, full tasks4/5/rendering and Steps6–8 remain separate.
