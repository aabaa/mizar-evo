## Published Export Metadata
`read_published_export_index(artifact_root: impl AsRef<Path>, expected_manifest_hash: Hash) -> Result<(PublishedManifestRead, BTreeMap<ModuleSummaryIdentity, Vec<VerifiedExport>>), ManifestError>` supplies raw published metadata for later build/index planning, using existing types only.
Call the existing [published reader](./artifact_reader.md#published-input-loading) with the required expected publication hash; retain its complete manifest/path/hash unchanged and propagate its existing validation/error layers without partial results. Add no read, codec, hash domain, cache, callback or production helper.
Move each complete VerifiedExport into the map under its full original ModuleSummaryIdentity. Use that existing Ord (package id, optional version, optional lock identity, module path, edition), not module path alone or parsed version order. Existing Manifest validation guarantees unique full module keys; keep modules with empty exports.
Within each module, sort by stored fully_qualified_name then origin_id using exact string order. Artifact's original origin-first order is different; its per-module origin uniqueness makes this a total order. Preserve duplicate FQNs, Public/Reexported visibility and every typed field/optional value; do not deduplicate, select a winner, parse names/signatures, derive labels or synthesize absent metadata.
An outer Manifest package is not independently equated to each entry's package tuple. Preserve those stored identities without inventing owning-package equality, source provenance, currentness, acceptance or link-resolution authority. Stored projected proof statuses remain data.
Three appended source-backed structural families cover normal/explicit metadata and FQN ordering, full identity collisions/duplicate FQNs/absent options, and empty modules plus delegated refusal/byte preservation. Reuse the genuine published-reader fixture and unchanged lower matrices; any private shared publisher needs three real family callers.
