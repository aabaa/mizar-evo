## Published Input Loading
`read_published_artifacts(artifact_root: impl AsRef<Path>, expected_manifest_hash: Hash) -> Result<(PublishedManifestRead, Vec<VerifiedArtifact>), ManifestError>` is a read-only consumer of one caller-selected publication. Use existing types only; preserve all typed fields and manifest module order, with no DocInput wrapper, new enum, field, adapter or hash profile; crate dependencies are Session and Artifact only.
First call existing read_manifest_file with expected_manifest_hash Some, validate_references true and validate_witness_files true; development-artifact loading stays false. Retain the returned manifest/path/hash unchanged. Existing Manifest validation owns schema, canonical ordering, portable paths, actual store/module/interface/implementation/source/version binding, exact witness coverage, sidecars and witness-file reachability.
Then load every manifest.modules entry through existing PublishedArtifactPath/read_published_artifact with its declared VerifiedArtifact store domain, original exclusions and expected artifact digest. Select the existing explicit enclosing-2.0 reader only for exact declared 2.0; otherwise use normal enclosing-1.0 reader. Supply actual path and expected module/interface/implementation hashes. Preserve ManifestError layers: StoreIo for path/store failures and VerifiedArtifact { path, boxed error } for nested reads. No decode-failure fallback or unsupported-version support is added.
The reload must match the same expected store hash used by the completed reference-validation pass. Its stable content therefore retains that pass's source/version/witness bindings; do not copy the private Manifest validation matrix or invent another store/codec. Local excluded metadata retains its existing meaning. Return nothing partially if any load fails; use no cache, source reread, mutation, callback or production helper.
This establishes published internal consistency only. Caller selection/hash is not current Disk/OpenBuffer, active policy/toolchain/snapshot or package-request freshness. Witness reachability is not Kernel acceptance or payload-to-accepted-result proof. Existing original normal/built-in classes stay data, not new acceptance/publication/reuse authority.
Three appended mizar-test families reuse original genuine witness producers and explicit caller-owned enclosing fixtures: normal/explicit profiles and multi-module canonical return/field preservation; otherwise-valid wrong manifest/store/source/module/hash/schema/coverage bindings; missing/malformed/unsafe files and witness reachability with preserved inputs. Reuse original Artifact matrices; no fabricated Accepted result, producer, evidence, Complete, freshness or cache hit. The Doc lint guard mirrors workspace inheritance/rustc warnings/Clippy all without copying Frontend-specific inventories.
## Optional Native Disk Source
`read_native_disk_source(package_root: impl AsRef<Path>, path: impl AsRef<Path>, expected_source_hash: Hash) -> std::io::Result<Option<(String, Option<Vec<LoadingMapSegment>>)>>` reads optional native Disk content only; the tuple reuses Session loading-map segments without allocating source/snapshot identities or introducing a wrapper, field, profile, dependency or helper.
First use existing Session normalize_source_path against the caller-selected package root; retain its native src/.miz/namespace/alias/confinement rules. Read that root joined to its returned package-relative path. Only SourcePathUnavailable with NotFound, or actual file-read NotFound, returns None; missing/invalid package root and every other error remain errors. Wrap the original SourcePathError in io::Error: preserve its recorded I/O kind for PackageRootUnavailable/SourcePathUnavailable, otherwise InvalidInput. Propagate other file I/O errors unchanged.
Validate UTF8 (InvalidData retaining Utf8Error), call existing normalize_source_text once, then compare existing hash_text of that normalized text with the required expected hash. Mismatch is io::ErrorKind::InvalidData, never absence or partial success. Return the entire normalization tuple on equality, including None or every original loading-map segment. These are internal read errors, not a new public diagnostic code or warning policy.
Session Disk rules strip exactly one leading BOM and replace CRLF with LF; lone CR/interior BOM remain. This is normalized-content equality, not raw-byte identity. Inputs and publication files are never written. Native source paths need not be the Artifact's stored path; the caller separately owns selecting/binding its package root, source coordinate and expected hash. Packaged/workspace-relative layouts, OpenBuffer and Generated origins are outside this API.
Three appended families cover a genuine existing source/artifact-hash read and preserved bytes, independent exact normalization/map cases, and optional absence versus root/path/UTF8/hash failures with edit/restore. Reuse existing fixtures/path validators rather than duplicating their full matrices.
Hash equality grants no owning-package authentication, item/range/adjacency/comment attachment, source currentness, atomic filesystem capture, acceptance, reuse or extraction readiness. Task6's comment-source decision, full build/index planning, source bundles and later diagnostic/rendering/extraction integration stay open.
