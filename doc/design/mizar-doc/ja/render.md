## Adopted Opaque Math Transport
Doc11 Q6/Q7/Q12 と Doc13 Q6/Q11 の opaque-client 部分だけを採用する。[英語の所有定義](../en/render.md#adopted-opaque-math-transport)が正本。[runtime](./math.md) と連携する `render::opaque_math_fragments` は ParsedComments を借用し、Doc8 block/occurrence 順に fragment を出す。MathRange interior segment のみを順に連結し、target/publication、outer range、独立 map は同じ ordinal の元入力に保持する。unavailable/不正範囲は拒否し、available-empty は空のままとする。page renderer/provenance schema は作らない。
inline span/display div の属性順は class、data-mizar-block、data-mizar-occurrence、data-mizar-display、data-mizar-tex。ordinal は unpadded decimal、payload は lowercase hex UTF-8 とし、entity/newline/NUL を正確に運ぶ。role=status と code 子要素を持つ pending fallback は HTML metacharacter を escape し、HTML が保存できない control を可視の `\u{hex}` とする。client fallback は元 payload の textContent を使い、payload から実行 source/innerHTML/URL を作らない。
local asset handoff は assets/katex/ の固定 path と immutable bytes を供給し、完全な manifest/configuration 集合の欠落・余剰・改変を拒否する。client は自身の script URL を基準に nested page からも local 資産を検証し、redirect/foreign origin を拒否する。検証済み bytes の blob URL だけを実行/CSS/font に用い、失敗時は fallback を保つ。完全 template、staging/publication は未解決のまま。

固定された所有者入力は採用済み [Doc8 Q9–Q18](./commonmark.md) と [Doc9 Q1–Q10](./links.md)。歴史的な候補/未選択表記は判断を再開しない。解析、tag 保持、厳密な参照比較、identity-keyed allocation、完全 FQN anchor、衝突しない optional alias、direct-by completeness 境界を保持する。採用は producer readiness を確立しない。

## 候補の配置と page 内容
以下は所有者検討用に統合候補①を保持し、上記採用済み Q3 href interface に従う。各 selected package を明示設定された output root に配置し、完全 package/version/lock/module/edition、publication hash、export origin/FQN を allocation table に保つ。root 衝突は package/version を選ばず拒否する。Doc4 は保存 version を必須とし、本経路は version なし planner や合成 version を追加しない。
Q1 は version root `doc_dir/v<component(version)>/` を提案する。内部で一成分 module `algebra` は `algebra/index.html`、入れ子の `algebra.groups.basic` は `algebra/groups/basic.html` を使う。item 専用 page は `<module-components>/items/<component(exported-label)>.html`。成分は権威ある構造化 path/label から得て、推測した FQN を分割しない。ASCII 英数字、`_`、`-`、`.` を残し、それ以外の UTF-8 byte は literal `~` も含め小文字 hex の `~hh` にする。`.`/`..` 内の全 dot と末尾 dot も符号化し、空成分は allocation を止める。これは URL 符号化とは別の filesystem 名候補である。
Q2 は出力前に予約 `index.html`、`search.json`、`assets/` を含む全配置について file/directory と ASCII 大小文字を同一視した path 衝突を確認し、衝突時は当該 package の site/search readiness を止める。従って `algebra` と `algebra.index` は `algebra/index.html` を黙って共有できない。異なる完全 identity を統合せず任意 suffix も付けない。完全 FQN id は module 一覧項目と専用 page の両方に必須で、承認済み Doc9 alias は全 full/section/他 alias id に対して確認する。Doc9 参照先は module page と anchor の組のまま、module 一覧はさらに専用 item page に link する。両配置は同じ完全 identity を指す。
Q3 の採用済み href interface は割当 path から相対 href を作り、各 path 成分で ASCII 英数字と `-._~` 以外の UTF-8 byte を percent 符号化し、完全な論理 fragment も同様に符号化する。区切りだけを `/` として残す。DOM id は厳密な FQN を属性 escape して保持し、正規化や notation slug を使わない。採用済み Doc9 は version-bound な仕様配置を要求する。残る Q3 source-routing 候補には artifact range に束縛された packaged source text/map と明示設定の source 配置/行規約が必要で、local 絶対 path、推測行、consumer による source fetch は使わない。source 欠落は unavailable と示して既存方針で warn し、厳密な source-view routing は Q3 の採用前提として残す。
Q4 は対象に別々に付いた block を source 順に見て、認識済み tag 段落を除く最初の通常 CommonMark 段落を summary とする。text/code は可視 text、link label/image alternative はその text、math は渡された不変 payload、soft/hard break は space、raw HTML token は literal spelling とし、ASCII whitespace を一 space に畳み端を除く。Unicode 正規化や切詰めはしない。利用可能 comment に対象段落がなければ `""`、既知の comment 不在は `null`。producer metadata unavailable はどちらでもない。承認済み Doc8 Q18 の conversion/map failure は代わりに当該 raw block を warning 付きで保持し、既定 build を継続する。劣化時の一行 summary/search 表現は Q4/MT の共同採用 gate として残し、最初の段落を捏造しない。item page は未知・不正・重複 tag を含む全 comment と全 tag occurrence を source 順に保持し、table と See also は view として置換・重複除去に使わない。正式 contract と説明 tag は区別する。
Q5 は下記の[採用済み出力方針](#採用済み-htmlurl-出力方針)に従う。raw HTML は visible escaped text、通常 URL は許可 scheme と安全な fallback を使い、raw/interpreted 値と Doc10 分類・解決を変えない。image も同じ gate を使い、生成時 remote fetch はしない。
Q6 の opaque math transport/runtime は上記の限定採用に従う。symbolic 入力、数式番号/参照は未解決の共同依存であり、annotation 代入は選択しない。asset は local/immutable/version-bound とし、runtime CDN、可変 download、数式間 state を許可しない。

## 候補の検索と補助 index
Q7 は UTF-8 JSON とし、top-level key 順を `format_version`（候補整数 `1`）、`package_version`（保存文字列）、`items`（配列）と提案する。各 item の key 順は `identity`、`fqn`、`kind`、`summary`、`signature`、`href`。`identity` は `[package_id, package_version, lock_identity, module_path, edition, origin_id, publication_hash]` の tuple で、所有者の canonical string を使い、null は lock identity 不在だけ、module_path は順序付き string 成分配列とする。厳密な所有者 encoding、kind spelling、format compatibility は採用前に列挙する必要がある。検索 wire format の提案であって Artifact/DocIndex schema 割当ではない。
selected package の exported/reexported item は完全な保存 identity ごとに一件ずつ含め、未記述 item や同じ FQN の別 identity も保持する。dependency は明示された documented export 経由だけで入り、closure を探索しない。`summary` は Q4 の文字列または既知不在の null、`signature` は TeX/HTML 変換しない権威ある保存 display string、`href` は割当専用 item page と完全 FQN fragment。既知の空文字列は空のまま。必須 identity/kind/signature 欠落、不完全 export、summary 入力欠落、allocation 未解決は Q8 により package の検索出力を止める。ただし承認済み block-local conversion/map recovery は readiness refusal の対象外で、Q4/MT の劣化 summary 定義を待つ。record 省略、signature 捏造、unavailable を null とすることはしない。
Q9 の client 検索は query を ASCII whitespace で分け、各 token が FQN/kind/non-null summary/signature の少なくとも一つに substring として現れることを要求する。ASCII A–Z だけ小文字化し他の code point を保持する。空 query は全 item を index 順に示し、locale 依存 ranking、stemming、Unicode 正規化は行わない。結果は text DOM node と検証済み href を使い HTML を注入しない。互換 local index の load/parse failure は検索 unavailable と示し、空結果を捏造しない。この browser 状態は新しい build diagnostic ではない。
architecture Step4 は cross-reference index、internal05 は UsedBy 出力も要求する。Q10 は別の cross-reference JSON に identity-bound resolved edge、direct-by reverse edge、承認済み配置、occurrence provenance、明示的 completeness state を含める候補とする。citation data 不在は空 graph ではない。具体的 field 名/compatibility と source occurrence 内の順序は Doc9/render の共同採用前提として残し、producer を捏造しない。任意の machine-readable DocIndex は opt-in で検索と分離し、schema/compatibility は Doc4/Doc13 の後続の整合的 index 定義、公開は Doc23 が所有する。どの index も proof/extraction authority を確立しない。

## 候補の決定性と failure 境界
Q11 は再現対象を page、search/cross-reference index、有効化した optional index、同梱 asset の相対 path と厳密 byte に定める。同じ束縛済み publication、source/map、lock context、dependency-index hash、option、renderer/schema/toolchain、asset version は列挙順や worker scheduling に関係なく等しい出力を与える。module は既存の完全 ModuleSummaryIdentity Ord、item は厳密 FQN、origin、最後に publication hash で整列し、意味上の import 順と source/tag/occurrence 順は別に保持する。検索も同じ identity 順を用い、locale collation や FQN だけの重複除去をしない。
候補①の HTML は固定 template/属性順、BOM なし UTF-8、template 改行 LF、末尾一 LF とする。JSON は compact、宣言した object key 順、quote/backslash/control に標準 JSON escape、他 Unicode は literal、末尾一 LF とする。補助 object は採用前に明示した canonical key 順が必要。保持 source payload の改行/spelling は data として escape し、template LF 規則で正規化しない。asset は固定 manifest から byte のまま copy する。timestamp、乱数 id、workspace/temp 絶対 path、hostname、locale、browser 生成 DOM は生成 byte から除く。browser の math 動作は Doc11 gate のままで、本提案は認証しない。
Q8 は必須の producer 提供 page/search projection 欠落時、当該 package の完全 site/search 生成だけを止める候補であり、部分 site に完全 export coverage を主張させない。承認済み Doc8 conversion/map failure は raw-block warning/degradation を保ち既定 build を中止せず、Q8 はこれを producer 入力欠落に分類し直さない。承認済み unresolved link は warning 付きの安全な unlinked text、不完全 UsedBy は明示 unavailable、source 欠落は既存 warning とし、内容を捏造しない。lower-reader integrity/schema/currentness refusal は error のままで presentation success にしない。上流 MT の意味と math failure handling は所有者の未解決 gate のままとし、HTML 方針 failure には render 診断の別途採用を要する。
Q12 は既存 Documentation 順序・provenance・profile 境界に従う。限定 [URL 診断](../../mizar-diagnostics/ja/documentation_urls.md) は採用済みだが、残る descriptor/location/overlap/failure precedence/profile は別途 owner の定義・採用を要し、それ以上の code を予約しない。限定検出・発行は採用済み。profile 失敗は documentation quality だけに影響し proof validity/extraction acceptance を変えない。Doc23 が staging/atomic replacement/write-failure cleanup を所有し、本提案は publication 実装を許可しない。

## 採用済み HTML/URL 出力方針
限定 Q5 採用の正本は [出力方針](../en/render.md#adopted-html-and-url-output-policy)。raw HTML は inline tag を含め literal spelling を context escape して表示し、警告しない。通常 URL-class link/image は CommonMark 解釈済み destination に正本の厳密な predicate を適用する。C0/DEL/backslash は拒否し、検査時だけ端の ASCII space を除く。最初の `/ ? #` より前の colon は正しい ASCII scheme と `http|https|mailto` の ASCII-case-insensitive 一致を要求する。それ以外は空・fragment・network-path を含む相対 URL とする。再 decode/修復せず raw/interpreted 値と Doc10 分類・解決を保持する。許可値は attribute escape し、拒否 link は href なしの label、image は src なしの代替 text を表示する。生成時に remote fetch しない。[診断](../../mizar-diagnostics/ja/documentation_urls.md) は別所有で、限定検出・発行を採用し、全体 renderer は gate 内に残る。

## 採用済み限定 URL Handoff
[English owner](../en/render.md#adopted-isolated-url-handoff) が正本。Doc8 は実 link/image/autolink event と raw destination range、厳密な CommonMark interpreted 値、元 block 内 occurrence ordinal を保持する。email autolink の暗黙 `mailto:` は Doc8 が供給し parser event は変更しない。Render は attachment から view を再導出し text/event/range の改変を拒否し、部分 map の元 source への binding と順序を検証する。参照式は選択 definition range を共有しても ordinal を区別する。Render は block ごとの完全な権威ある Doc10 分類 vector を受け、既存 resolver の認証・解決後に限定 fragment と既存 warning を返す。External のみ URL とし Ordinary は意図的な非リンク、Unavailable は推測しない。failed block は destination を持たず、unavailable は拒否し available-empty は空。許可 URL と raw HTML を escape し、拒否 URL は可視 label/代替 text と W0415 にする。完全 page、semantic link rendering と publication は gate 内。
