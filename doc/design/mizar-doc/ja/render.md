## Adopted Opaque Math Transport
Doc11 Q6/Q7/Q12 と Doc13 Q6/Q11 の opaque-client 部分だけを採用する。[英語の所有定義](../en/render.md#adopted-opaque-math-transport)が正本。[runtime](./math.md) と連携する `render::opaque_math_fragments` は ParsedComments を借用し、Doc8 block/occurrence 順に fragment を出す。MathRange interior segment のみを順に連結し、target/publication、outer range、独立 map は同じ ordinal の元入力に保持する。unavailable/不正範囲は拒否し、available-empty は空のままとする。page renderer/provenance schema は作らない。
inline span/display div の属性順は class、data-mizar-block、data-mizar-occurrence、data-mizar-display、data-mizar-tex。ordinal は unpadded decimal、payload は lowercase hex UTF-8 とし、entity/newline/NUL を正確に運ぶ。role=status と code 子要素を持つ pending fallback は HTML metacharacter を escape し、HTML が保存できない control を可視の `\u{hex}` とする。client fallback は元 payload の textContent を使い、payload から実行 source/innerHTML/URL を作らない。
local asset handoff は assets/katex/ の固定 path と immutable bytes を供給し、完全な manifest/configuration 集合の欠落・余剰・改変を拒否する。client は自身の script URL を基準に nested page からも local 資産を検証し、redirect/foreign origin を拒否する。検証済み bytes の blob URL だけを実行/CSS/font に用い、失敗時は fallback を保つ。完全 template、staging/publication は未解決のまま。

固定された所有者入力は採用済み [Doc8 Q9–Q18](./commonmark.md) と [Doc9 Q1–Q10](./links.md)。歴史的な候補/未選択表記は判断を再開しない。解析、tag 保持、厳密な参照比較、identity-keyed allocation、完全 FQN anchor、衝突しない optional alias、direct-by completeness 境界を保持する。採用は producer readiness を確立しない。

module index は module comment、全 export の数学的 signature、最初の段落から得る一行 summary、完全な item への link を示す。item page は完全な signature/statement、HTML comment 全文、数学的な正式 requires/ensures、parameter/returns table、Used by、See also、artifact range に基づく source 行 link を含む。必須内容を架空の式、引用、label、source location で置換しない。

## 候補の配置と page 内容
以下は所有者検討用に統合候補①を保持し、上記採用済み Q3 href interface に従う。各 selected package を明示設定された output root に配置し、完全 package/version/lock/module/edition、publication hash、export origin/FQN を allocation table に保つ。root 衝突は package/version を選ばず拒否する。Doc4 は保存 version を必須とし、本経路は version なし planner や合成 version を追加しない。
Q1 は version root `doc_dir/v<component(version)>/` を提案する。内部で一成分 module `algebra` は `algebra/index.html`、入れ子の `algebra.groups.basic` は `algebra/groups/basic.html` を使う。item 専用 page は `<module-components>/items/<component(exported-label)>.html`。成分は権威ある構造化 path/label から得て、推測した FQN を分割しない。ASCII 英数字、`_`、`-`、`.` を残し、それ以外の UTF-8 byte は literal `~` も含め小文字 hex の `~hh` にする。`.`/`..` 内の全 dot と末尾 dot も符号化し、空成分は allocation を止める。これは URL 符号化とは別の filesystem 名候補である。
Q2 は出力前に予約 `index.html`、`search.json`、`assets/` を含む全配置について file/directory と ASCII 大小文字を同一視した path 衝突を確認し、衝突時は当該 package の site/search readiness を止める。従って `algebra` と `algebra.index` は `algebra/index.html` を黙って共有できない。異なる完全 identity を統合せず任意 suffix も付けない。完全 FQN id は module 一覧項目と専用 page の両方に必須で、承認済み Doc9 alias は全 full/section/他 alias id に対して確認する。Doc9 参照先は module page と anchor の組のまま、module 一覧はさらに専用 item page に link する。両配置は同じ完全 identity を指す。
Q3 の採用済み href interface は割当 path から相対 href を作り、各 path 成分で ASCII 英数字と `-._~` 以外の UTF-8 byte を percent 符号化し、完全な論理 fragment も同様に符号化する。区切りだけを `/` として残す。DOM id は厳密な FQN を属性 escape して保持し、正規化や notation slug を使わない。採用済み Doc9 は version-bound な仕様配置を要求する。[限定 Q3 source-view/行定義](#q3-source-view-and-line-routing-definition) は packaged original text/map を artifact range に束縛するが、限定実行 handoff は下記に定める。source 欠落は unavailable と示し既存方針で warn する。
Q4 は限定[共同 summary/search 定義](#joint-q4mt-summary-definition)に従う。item page は未知・不正・重複 tag を含む全 comment と全 tag occurrence を source 順に保持し、table と See also は view として置換・重複除去に使わない。正式 contract と説明 tag は区別する。
Q5 は下記の[採用済み出力方針](#採用済み-htmlurl-出力方針)に従う。raw HTML は visible escaped text、通常 URL は許可 scheme と安全な fallback を使い、raw/interpreted 値と Doc10 分類・解決を変えない。image も同じ gate を使い、生成時 remote fetch はしない。
Q6 の opaque math transport/runtime は上記の限定採用に従う。symbolic 入力、数式番号/参照は未解決の共同依存であり、annotation 代入は選択しない。asset は local/immutable/version-bound とし、runtime CDN、可変 download、数式間 state を許可しない。

## Joint Q4/MT Summary Definition
限定 consumer 定義として、採用済み [Doc8 recovery](./commonmark.md) と [MT precedence](../../../spec/ja/22.error_handling_and_diagnostics.md) の下で Q4 の劣化 module/search text 投影を定める。下記の独立した実行 projection を採用するが、parser、serialized status field、完全 renderer は定義しない。この投影についてのみ、以下が Q4 の歴史的な提案選択肢に優先する。

### Selection And Recovery
同じ完全 provenance の target/publication と完全な source 順 attachment list に入力を結び付ける。Doc8 view と map が完了した各 block の通常 CommonMark 段落を、container 内の構造的段落も含め source 順に走査する。Doc8 の認識に従い、必須 field 欠落・重複を含む既知 tag 段落を除く。未知・類似 tag は通常 text のまま。heading、code/HTML block、reference definition、display math を段落に変えない。これらの block 全体で最初の対象段落を flatten 前に選び、結果が空でも後の非空段落を探さない。
実際の conversion/map failure では当該 block 全体の失敗 view を選択から除く。保持された raw fallback を再 parse・分割・flatten したり通常段落と見なしたりせず、成功した隣接 block を元の順で走査する。劣化 summary は最初の対象 *successful-view* 段落であり、失敗 block の最初の段落を復元したとは主張しない。完全 raw block、元 block identity/map/provenance、既存 W0411 動作を documentation 入力・全文 comment 表示に保持し、空・後続 summary によって失敗を消さない。warning occurrence、条件 detail、location、順序、promotion は MT が所有し、summary 専用 warning や status prefix は加えない。選択段落の後の失敗は text を変えず、前の失敗は成功した隣接段落を隠さない。

### Exact Text And States
選択段落は既存 Q4 規則通り、text/code を可視 text、link label/image alternative をその text、math を渡された不変 payload、soft/hard break を space、raw HTML token を literal spelling にする。ASCII whitespace を一 space に畳み端を除き、Unicode 正規化・切詰めをしない。plain text として扱い、context escape は最後の HTML/JSON sink のみで行い、render 済み HTML から text を抽出しない。math runtime 成否、link 解決、highlight は summary text を変えない。
comment の既知不在は search では null、module summary の可視 text では空。利用可能 comment に対象 successful 段落がなければ `""` とし、tag-only、non-paragraph-only、all-failed も含む。all-failed は raw recovery のままで既知不在ではない。利用可能な空 text や選択段落の flatten 結果が空でも `""`。必須 attachment/order/target/view-state 入力 unavailable は不在・available-empty のどちらにもせず既存 readiness 境界を保つ。所有者が失敗を確定し raw fallback を保持した block は available recovered 入力であり metadata 欠落ではない。lower-reader integrity/schema/currentness refusal は error のまま。

| Source 順 block（通常段落は text で表示） | 共同 summary text |
|---|---|
| failed, `Alpha`, `Beta` | `Alpha` |
| `Alpha`, failed, `Beta` | `Alpha` |
| failed, tag-only, failed, `Beta` | `Beta` |
| failed, failed | `""`。両 raw block と既存 warning を保持 |

### Module And Search Boundary
module listing と search record は exported/reexported 完全 identity ごとに同じ選択済み plain string を使い、全 export と既存 index 順を保持する。search null は既知不在だけとし、recovery による record 省略、新たな Q8 refusal、raw text/error label の summary 挿入はしない。全文 comment と全 tag occurrence は別の source 順 content として保持し、summary で置換・重複除去しない。warning promotion は既存 profile の documentation のみで proof/extraction acceptance を変えない。完全 template/search serialization、残る math/owner fragment、Q12 定義、Doc13/G4 全体、G5/Doc14–15、schema/publication、Doc23/24、credit は gate 内に保つ。
独立した Render `summary_text` selector は `ParsedComments` と bound target を借用する。`search_summaries` は元の export 参照と optional plain string を入力順で保持し、`module_summary_fragments` は同じ文字列を一度 escape して `<p class="mizar-summary">{text}</p>` と末尾 LF を生成する。既知不在は空の可視 text。unavailable/incomplete view-state と foreign target binding は既存 binding refusal 境界を保ち、recovered block は available 入力のままとする。

## 候補の検索と補助 index
Q7 は UTF-8 JSON とし、top-level key 順を `format_version`（候補整数 `1`）、`package_version`（保存文字列）、`items`（配列）と提案する。各 item の key 順は `identity`、`fqn`、`kind`、`summary`、`signature`、`href`。`identity` は `[package_id, package_version, lock_identity, module_path, edition, origin_id, publication_hash]` の tuple で、所有者の canonical string を使い、null は lock identity 不在だけ、module_path は順序付き string 成分配列とする。[採用済み限定 search interface](../en/render_prerequisites.md#proposed-search-encoding-and-compatibility) が厳密な encoding、kind/version binding、compatibility を所有する。完全 search 合成/serialization は未実装で、Artifact/DocIndex schema 割当ではない。
selected package の exported/reexported item は完全な保存 identity ごとに一件ずつ含め、未記述 item や同じ FQN の別 identity も保持する。dependency は明示された documented export 経由だけで入り、closure を探索しない。`summary` は Q4 の文字列または既知不在の null、`signature` は TeX/HTML 変換しない権威ある保存 display string、`href` は割当専用 item page と完全 FQN fragment。既知の空文字列は空のまま。必須 identity/kind/signature 欠落、不完全 export、summary 入力欠落、allocation 未解決は Q8 により package の検索出力を止める。ただし承認済み block-local conversion/map recovery は readiness refusal の対象外で、共同 Q4/MT summary 定義に従う。record 省略、signature 捏造、unavailable を null とすることはしない。
Q9 の client 検索は query を ASCII whitespace で分け、各 token が FQN/kind/non-null summary/signature の少なくとも一つに substring として現れることを要求する。ASCII A–Z だけ小文字化し他の code point を保持する。空 query は全 item を index 順に示し、locale 依存 ranking、stemming、Unicode 正規化は行わない。結果は text DOM node と検証済み href を使い HTML を注入しない。互換 local index の load/parse failure は検索 unavailable と示し、空結果を捏造しない。この browser 状態は新しい build diagnostic ではない。
architecture Step4 は cross-reference index、internal05 は UsedBy 出力も要求する。Q10 は別の cross-reference JSON に identity-bound resolved edge、direct-by reverse edge、承認済み配置、occurrence provenance、明示的 completeness state を含める候補とする。citation data 不在は空 graph ではない。[採用済み限定補助 interface](../en/render_prerequisites.md#proposed-cross-reference-and-usedby-serialization) が具体的 field、compatibility、順序を所有する。認証済みの元 reference encounter ordinal は producer gate のままで、出力列挙から推測しない。任意の machine-readable DocIndex は opt-in で検索と分離し、schema/compatibility は Doc4/Doc13 の後続の整合的 index 定義、公開は Doc23 が所有する。どの index も proof/extraction authority を確立しない。

## 候補の決定性と failure 境界
Q11 は再現対象を page、search/cross-reference index、有効化した optional index、同梱 asset の相対 path と厳密 byte に定める。同じ束縛済み publication、source/map、lock context、dependency-index hash、option、renderer/schema/toolchain、asset version は列挙順や worker scheduling に関係なく等しい出力を与える。module は既存の完全 ModuleSummaryIdentity Ord、item は厳密 FQN、origin、最後に publication hash で整列し、意味上の import 順と source/tag/occurrence 順は別に保持する。検索も同じ identity 順を用い、locale collation や FQN だけの重複除去をしない。
候補①の HTML は固定 template/属性順、BOM なし UTF-8、template 改行 LF、末尾一 LF とする。JSON は compact、宣言した object key 順、quote/backslash/control に標準 JSON escape、他 Unicode は literal、末尾一 LF とする。補助 object は[採用済み canonical key 順](../en/render_prerequisites.md#proposed-cross-reference-and-usedby-serialization)を使う。保持 source payload の改行/spelling は data として escape し、template LF 規則で正規化しない。asset は固定 manifest から byte のまま copy する。timestamp、乱数 id、workspace/temp 絶対 path、hostname、locale、browser 生成 DOM は生成 byte から除く。browser の math 動作は Doc11 gate のままで、本提案は認証しない。
Q8 は必須の producer 提供 page/search projection 欠落時、当該 package の完全 site/search 生成だけを止める候補であり、部分 site に完全 export coverage を主張させない。承認済み Doc8 conversion/map failure は raw-block warning/degradation を保ち既定 build を中止せず、Q8 はこれを producer 入力欠落に分類し直さない。承認済み unresolved link は warning 付きの安全な unlinked text、不完全 UsedBy は明示 unavailable、source 欠落は既存 warning とし、内容を捏造しない。lower-reader integrity/schema/currentness refusal は error のままで presentation success にしない。上流 MT の意味と math failure handling は所有者の未解決 gate のままとし、HTML 方針 failure には render 診断の別途採用を要する。
Q12 は既存 Documentation 順序・provenance・profile 境界に従う。限定 [URL 診断](../../mizar-diagnostics/ja/documentation_urls.md) は採用済みだが、残る descriptor/location/overlap/failure precedence/profile は別途 owner の定義・採用を要し、それ以上の code を予約しない。限定検出・発行は採用済み。profile 失敗は documentation quality だけに影響し proof validity/extraction acceptance を変えない。Doc23 が staging/atomic replacement/write-failure cleanup を所有し、本提案は publication 実装を許可しない。

## 採用済み HTML/URL 出力方針
限定 Q5 採用の正本は [出力方針](../en/render.md#adopted-html-and-url-output-policy)。raw HTML は inline tag を含め literal spelling を context escape して表示し、警告しない。通常 URL-class link/image は CommonMark 解釈済み destination に正本の厳密な predicate を適用する。C0/DEL/backslash は拒否し、検査時だけ端の ASCII space を除く。最初の `/ ? #` より前の colon は正しい ASCII scheme と `http|https|mailto` の ASCII-case-insensitive 一致を要求する。それ以外は空・fragment・network-path を含む相対 URL とする。再 decode/修復せず raw/interpreted 値と Doc10 分類・解決を保持する。許可値は attribute escape し、拒否 link は href なしの label、image は src なしの代替 text を表示する。生成時に remote fetch しない。[診断](../../mizar-diagnostics/ja/documentation_urls.md) は別所有で、限定検出・発行を採用し、全体 renderer は gate 内に残る。

## 採用済み限定 URL Handoff

## Q3 Source-View And Line Routing Definition
Render 所有の限定 local source 表示/routing 定義である。local source 表示/routing のみを採用し、完全 Doc13 や Q12 診断は供給しない。[G3 original-coordinate 認証](./render_prerequisites.md#採用済み-g3-source-coordinates)を使い、正規化済み hash や独立に開き直した source file は使わない。`AuthenticatedDocSources::original_text` は厳密 binding を検証して同じ保持済み original text を参照する。`render::DocSourceViews::allocate` は source view を完全 G2 namespace に加え、不変 sources/inputs を保持する。`view` は owner 供給の package display name を必須とし認証 version の固定 shell、`item_source_slot` は G3 を通した認証 export range を描画する。`loaded_source_slot` は順序付き loaded-frame range を同じ G3 合成で受け取り、original segment と mapping coverage は G3 が保持する。出力は in-memory HTML のみ。

### Binding And Destinations
selected package/version output root 内で `sources/` に認証済み packaged relative source path の成分を続け、最終成分に `.html` を追加する（`src/a.miz` は `sources/src/a.miz.html`）。完全 module identity、publication hash、厳密 packaged path、G3 original digest に配置を束縛する。FQN 分割、host path、source fetch、別/native text を binding に使わない。同一 binding だけが view を共有し、text/path が同じだけの異なる binding は統合しない。
全 source view を G2 の完全 auxiliary namespace に宣言してから配置し、generated page、file/directory、予約 asset、ASCII 大小文字衝突を一緒に検証する。衝突は当該配置の拒否とし suffix や identity winner を作らない。source view は新しい export/semantic destination ではない。包含 page からの相対 link は採用済み Q3 の成分別 percent-UTF8 と完全 fragment encoding 後に一度属性 escape し、二重 encode や packaged path の URL 解釈をしない。

### Original Lines And Segment Links
認証 original UTF-8 text 自体から、ゼロと各 LF の直後の offset を行開始とする。行番号は 1 始まりのゼロ埋めなし十進、anchor は `L1`、`L2` 等。Session の LF 規約に従うが loaded-text LineMap を original offset に適用しない。CRLF は LF 後に進み、単独 CR は進まない。空 text に行 1 があり、末尾 LF は空最終行を作る。text length と等しい offset は有効、範囲外や UTF-8 code point 内部は binding を拒否する。
item Source slot は artifact `source_range` だけを認証 loaded frame の G3 `loaded_ranges` 経由で使う。将来 comment/citation link を求める consumer は既存の frame 別 G3 composition を使い、lexical/loaded offset を original に読み替えない。返された original 半開 segment ごとに開始を含む行（開始 offset 以下の最大行開始）へ link する。segment 順序、反復、厳密 endpoint、source binding、mapping state は表示 projection 外に保持し、結合や covering range/highlight を作らない。非空 segment の排他的末尾は追加 link を作らず、認証された空 segment は EOF を含む点とする。source text があっても segment がなければ行 link はない。partial map は既知 segment link と incomplete state を保持し、map 欠落から offset ゼロや行 1 を捏造しない。

### Source View And Source Slot
既存 page shell を使い、`title` は厳密 packaged path、header は束縛 package/version とする。BODY は下記 literal で、後述 template 展開/escape 規則を使う。shell 以外の search/math hook は加えない。
```html
<ol class="mizar-source-lines">{SOURCE-LINES}</ol>
```
SOURCE-LINES は original の各行に `<li id="L{A:line}"><pre><code>{T:source-line}</code></pre></li>` と LF の row を連結する。行 slice からは末尾 LF だけを除く。表示 source text の C0 control（tab を除く）と DEL は小文字ゼロ埋めなし hex の `\u{hex}` とし、その後 T escape を一度適用する。CR は original LF 行内で可視になり、source 文字を HTML、script、highlight markup に入れない。これは表示 projection であり source 改変や復元可能 byte serialization ではなく、認証 original byte/map を不変に保つ。空行も anchor を持ち、row/order は export/comment 列挙から独立する。
item `source` flow slot は `<p class="mizar-source">Source: {SOURCE-LINKS}{MAPPING}</p>` と LF。SOURCE-LINKS は segment 順の `<a href="{A:source-href}">line {T:line}</a>` を `; ` で区切る。MAPPING は complete 時は空、incomplete map に link が残る場合は厳密に ` <span class="mizar-source-mapping">incomplete mapping</span>`。網羅的 source location や reference/citation coverage の complete を意味しない。
original source unavailable の slot 全体は `<p class="mizar-source-unavailable">Source unavailable</p>` と LF とし、view を配置せず、source が packaged でない場合の既存 warning を保持する。legacy projection/map metadata unavailable だけでは warning を追加しない。認証 text はあるが mapped segment がなければ `<p class="mizar-source-unavailable">Source location unavailable</p>` と LF とする。view は存在し得るが、行 href を捏造せず map gap を source 欠落にしない。新しい warning/code/location/deduplication/precedence/profile は割り当てず、残る Q12 定義は Diagnostics が所有する。矛盾・stale binding と lower-reader failure は拒否のままで unavailable 表示にしない。Q4/MT、G4/G5、schema/publication、後続 gate の完了は供給しない。

## Complete-Page Template Definition
限定された Render 所有の G4 定義であり、採用・実行可能な完了証拠ではない。[英語正本の literal と slot 定義](../en/render.md#complete-page-template-definition) を package/module/item の唯一の template とする。style/search bytes、immutable manifest、整合 Doc13、後続 gate は供給しない。

### Expansion And Canonical Bytes
`{T:name}` は text、`{A:name}` は二重引用符属性で、元の `& < > " '` をそれぞれ `&amp; &lt; &gt; &quot; &#39;` に一度だけ置換し、生成した escape を再走査しない。他の UTF-8 byte と payload の改行は保持する。これは生成 byte の規約であり browser DOM の round-trip 同値ではない。`{F:name}` は所有者が安全に render した fragment の verbatim 挿入で、記述された raw HTML を直接挿入しない。`{X}` は正本の別 expansion。slot の内容を template として再解釈しない。
正本 fence 内の全 literal 行と各 row の末尾は LF。row は separator なしで連結し、available-empty collection は zero bytes。fragment の末尾 LF も保持し、indent、trim、改行正規化、再 escape、DOM serialize は行わない。UTF-8 BOM なし、正本の whitespace/属性順と page 最終一 LF を固定し、日時・random id・絶対 path・locale/browser 由来出力を含めない。
`title` は package 表示名、module 表示名または厳密 FQN、`package` は保存済み package 表示名。VERSION は権威ある version 不在時のみ空で、存在時（空文字列を含む）は正本の version span。Doc4 の選択済み route は保存 version を引き続き要求する。href/src は実際の包含 page から割当先への相対値を採用済み Q3 で符号化後に A escape し、FQN 分割や path 推測、二重 percent encoding、URL 書換えをしない。

### Page Shell And Bodies
正本の shell は doctype/head、local stylesheet、defer search/math client、package/version header、検索 UI、main/title/BODY を固定する。package BODY は overview と module 一覧、module BODY は全文 comment と全 export の FQN link・数学的 signature・summary。item BODY は厳密 FQN article、signature/statement、全文 comment、formal requires/ensures、param/returns table、Used by、See also、Source をこの順で配置する。全 tag、属性順、row literal、whitespace は正本通りである。
ALIAS は検証済み allocation が抑制する場合 zero bytes、存在時は正本の span だけで末尾 LF なし。module row と専用 article の完全 FQN id は不変であり、alias は別 identity を作らない。MODULES は完全 module identity 順、EXPORTS は Q11 の FQN/origin/publication 順で未記述・reexported item も完全 identity ごとに保持する。異なる identity は統合しない。item link は専用先と完全 fragment、semantic reference は module page と完全 fragment を保持する。PARAMS と SEE は元 block/tag 順に全 occurrence を保持し、全文 comment から取り除かず、prose tag を formal contract にしない。

### Owner Slots And DOM Hooks
overview は [package-level owner 入力定義](#package-overview-input-definition)に従う。overview/comment/tag body は documentation owner の安全な flow fragment、see-entry は Doc9 resolution を保持する phrasing fragment。summary は recovered block を含む[共同 Q4/MT 定義](#joint-q4mt-summary-definition)に従い、既知不在の可視 text は空、必須入力 unavailable は未充足 slot のまま。signature/statement/formal requires/ensures は適用性・既知不在を含め Doc11 の数学的 flow fragment を要し、source string への代替表示は選ばない。Used-by は Doc9 の flow 表示で citing identity 順・重複排除済み表示・明示的 incomplete/unavailable coverage を保持する。Source は[限定 Q3 source-slot 定義](#q3-source-view-and-line-routing-definition)に従い、Q12 diagnostic descriptor と完全 page producer は別 gate に保つ。
所有者の未定義・未供給は未充足 slot であり、暗黙の空文字列・架空 node・新たな build refusal/diagnostic にしない。採用済み block-local recovery と lower-reader refusal は変更しない。complete-comment は Doc8 順序・保持 tag/raw content・recovery を保ち、採用済み URL/raw-HTML fragment を二重 escape や label HTML の反復なしで合成する。semantic link は Doc9 が所有する。
opaque math fragment は有効な flow/phrasing 位置へ verbatim 挿入し、`.mizar-math[data-mizar-tex]`、status/code child、hex payload、元の block/occurrence/display 属性を保持する。display div を paragraph/link 内に置かない。symbolic math/numbering は未解決 owner slot で Doc8 ordinal を転用しない。
style/search-script/math-client/search-index は version root 内の `assets/style.css`、`assets/search.js`、`assets/katex/client.js`、`search.json` を指す。inline script/style、remote dependency、未検証 KaTeX の直接 load は追加しない。math client は自身の URL から immutable subtree を検証して runtime/CSS/font を load する既存契約を保持する。
search は各 `.mizar-search` 内の `.mizar-search-query`、`.mizar-search-status`、`.mizar-search-results` と `data-mizar-index` を使う。compatible local data と Q9 matching/index 順を保持する。index 内の version-root 相対 href は search-index directory から包含 page への相対値に rebase して result-href とし、既存 percent escape と fragment を保持する。nested page に直接相対解釈したり再符号化したりしない。正本の result row の FQN/kind/summary/signature は text node、href は検証済み属性とし innerHTML にしない。summary の既知不在 null は空 text、未解決は null でない。browser status/result 更新は canonical page bytes 外で、load/compatibility 失敗は空 match 集合でなく既存 Q9 の search unavailable とする。完全 template の実行 witness は別義務のままである。

## Package Overview Input Definition
package template の `{F:package-overview}` 入力だけを定める限定定義であり、producer・API・serialized field・source syntax・完全 page 実装は採用しない。documentation owner は Doc の package-content 入力 producer で、[Doc8 module/item attachment owner](../en/comments.md#blocks-and-attachment-targets)とは別である。将来の採用と真正な production witness は前提条件のまま。

### Selection And Authentication
owner は選択 root の documentation request に対し、一つの完全な package overview content product を明示選択するか、その完全な選択に overview がないと明示宣言する。不変の選択、owner provenance、owner 表現の全文 content（元順序と利用可能な source/map provenance を含む）を保持する。不在宣言は明示した選択の完全性に対するもので、disk 上の全候補文書を調査した意味ではない。filename/discovery 規約は選ばず、README・manifest description・source header・module comment・dependency document から暗黙に content や不在を導かない。file-leading Doc8 comment は module-only のまま。
[現在の選択 root plan](./doc_build.md#package-planning) の正確な package id・必須の保存 version・optional lock identity・publication hash と、選択 snapshot/request・documentation option に product を束縛する。payload または不在宣言とともに owner の正確な content identity と選択 evidence を保持し、自己申告 hash/package tuple だけを認証としない。選択に厳密一致する一 product を必要とし、重複/矛盾・foreign・dependency-only・stale・改変 product は root slot を満たさない。同名/version を理由に publication/request を越えて再利用せず、winner を選ばない。
owner producer だけが保持された選択/content を検証し、下記の所有 rendering 規則による完全 safe fragment を導出して ready handoff を成立させる。consumer は保持 owner evidence に対する currentness・厳密 binding を再検証し、caller HTML・safe flag の主張・digest 一致・package plan 単独から readiness を作らない。content・選択・rendering 入力/option・包含 page destination の変更時は owner の再導出/検証を要する。これは将来の実装への認証義務であり、新 signature/hash domain や既存 producer の対応宣言ではない。

### Safe Flow And Slot States
available content は選択した全文を owner 順に含む一つの完全 safe flow fragment を供給する。適用可能な採用済み [HTML/URL 方針](../en/render.md#adopted-html-and-url-output-policy)・[comment safe-flow 規則](../en/render.md#adopted-comment-and-tag-safe-flow-handoff)・opaque math transport を再利用し、authored HTML を escape し、URL classification/Doc9 resolution と raw-block recovery/warning を保つ。これらは出力安全性の規則であり、package text の module/item attachment、prose の formal contract 化、新 parser/source adapter を許可しない。
semantic reference は owner が明示束縛した Doc9 lookup context/classification を要し、package name/path/module 列挙から current module を推測しない。必須 context/safe-rendering 入力の欠落は unavailable とし、既存の認証済み unresolved/incomplete 結果は承認済み safe 表示を保つ。包含 page に一致する検証済み destination と既存 Q3 rebasing を用いる。opaque math payload/属性と正しい flow/phrasing 位置を保持し、symbolic math は owner gate のまま。sanitizer や任意 authored HTML で真正 owner 導出を代用しない。

矛盾/stale binding と lower-reader integrity/schema/currentness refusal は既存 error の意味を保ち、正常な unavailable/absent 表示にしない。Q12 descriptor・severity・location・precedence・warning promotion・complete-build 結果は割り当てない。package Modules expansion は独立したまま。完全 rendering/search/auxiliary interface 採用、残る owner slot/Q12、G4/G5 実行 witness、schema/publication、Doc23/24、completion credit は[順序付き前提条件](./render_prerequisites.md#順序付き-readiness-gate)の gate 内に残る。

## Adopted Local Style And Search Assets
status と results hook は別要素で相互に包含しないこと。重複する hook は load/query binding 前に search unavailable とする。
`render::bundled_search_assets` は固定 `assets/style.css`、`assets/search.js`、`assets/search-manifest.json` bytes を供給する。不変 manifest は CSS/JS の SHA-256 digest を固定し、`validate_search_assets` は manifest を含む欠落・余剰・重複・改変を integration 前に拒否する。bundled bytes との handoff 認証であり、browser 自己 integrity や site publication を保証しない。remote dependency はなく、CSS は label/status、keyboard focus、text wrapping を保持する。
単独 client は [supplied-search reader 契約](./render_prerequisites.md#adopted-g4-supplied-search-reader) と上記 scoped hook/text-only result shape だけを消費する。Q9 ASCII whitespace は U+0009–000D と U+0020。status 文言と CSS は presentation 判断であり、完全 page renderer、index producer、owner-slot fallback は供給しない。
