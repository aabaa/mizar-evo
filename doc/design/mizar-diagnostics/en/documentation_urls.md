## Descriptor And Details
Allocate W0415, semantic name and immutable meaning key `documentation.render.rejected_url`, summary `Documentation URL is rejected by output policy`, family `Documentation`, default `Warning`, phase `Documentation`, category `DocumentationWarning`. Lifecycle is active with empty aliases/retirement/replacements; `since = DOC13-G4-URL-POLICY-DIAGNOSTIC-PREREQUISITES`; `doc_url = doc/design/mizar-doc/en/render.md#adopted-html-and-url-output-policy`. The condition is one ordinary URL-class link/image occurrence rejected by that output predicate. Raw HTML alone never warns.
Use `stable_detail_key = semantic_name` and exactly these String/List details, without a shared schema validator or factory:
- `documentation.occurrence`: existing [occurrence tuple](./failure_record.md#markdowntag-occurrence-details) `[publication, module, target, block, reason, offsets]`; reason equals the semantic name, offsets are the destination's nonempty half-open Doc8 logical range. Retain the full verified target, lowercase publication hash, optional-value distinctions and canonical decimal Strings.
- `documentation.render.url`: `[kind, ordinal, raw, interpreted]`, where kind is `link|image`, ordinal is the true zero-based block-local destination occurrence ordinal, raw is the exact authored destination spelling and interpreted is its exact CommonMark value. Neither is normalized or substituted. The ordinal preserves distinct repeated/coincident occurrences; output enumeration cannot invent it.

## Locations And Precedence
Select the first complete contiguous source-bound mapped destination segment as primary, with remaining independently mapped segments as secondary spans in logical encounter order. Never bridge gaps or take a range from display text. With no usable segment use the existing [Documentation block provenance](./failure_record.md#documentation-primary-locations) at the true block ordinal; this descriptor explicitly permits that location. No module-scope warning, guessed span/EOF or source lookup is introduced.
One warning per rejected destination occurrence: rejected scheme and control/backslash conditions overlap into this single meaning. Accepted URLs, raw HTML, ordinary code and semantic Doc10 references do not warn here. Doc10 determines classification first: its unresolved/ambiguous/incomplete reference warnings cannot combine with this warning for the same destination. Lower-reader integrity/schema/binding/currentness refusal retains its error and suppresses dependent drafts; a Doc8 failed conversion/map view keeps its existing block warning and supplies no invented URL occurrences. Other blocks remain independent. Detection/emission witnesses for these conditions remain gated.
