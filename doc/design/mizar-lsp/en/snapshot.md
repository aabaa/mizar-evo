# Editor snapshot and freshness boundary
Canonical language: English; [Japanese companion](../ja/snapshot.md).

## Responsibility

LSP owns immutable editor reads and freshness under [architecture12](../../architecture/en/12.diagnostics_and_lsp.md#lsp-reads-stable-snapshots) and [internal03](../../internal/en/03.diagnostics_model_and_lsp_bridge.md#lsp-snapshot). Session owns source acquisition/maps/leases; IR owns sealed output validity and retention; Driver owns build scheduling/currentness; Artifact owns manifests and published metadata. No compiler or proof authority moves into LSP.

## Source association

Use the actual [originating capture](server.md#originating-native-open-buffer-capture), preserving its original source/map objects and URI/version/raw-text/open-incarnation relations. A BuildSnapshotId identifies normalized build inputs; it does not identify a document version, raw loading maps, open incarnation or publication generation. Accepted version-only and normalization-equivalent raw edits must invalidate the old editor association even when the build id stays equal. An identical-tuple reopen is a new incarnation.

A read retains one immutable association for its whole duration. Replacement makes later reads select the new association; existing reads keep their original values and retention until finished. Never mix maps, diagnostics, versions or metadata from old/new reads. Validate exact current document tuples and originating incarnations before current delivery, using the existing native guards as well; a stored id or retained handle cannot replace those checks.

## Retained native sources

`Server::capture_native_open_buffers<A: SessionIdAllocator + Send + Sync + 'static>(&mut self, draft: BuildRequestDraft, allocator: &A, snapshots: &Arc<SnapshotRegistry<A>>, index: &ModuleIndex, sources: Vec<(DiskSourceLoader, PackageId, String)>) -> Result<NativeOpenBufferCapture, String>` keeps Server nongeneric and requires a live initialized connection and distinct nonempty exact URI keys. Read each current document entry once; reject absent/closed documents and negative i32 versions without changing protocol acceptance. Derive OpenBuffer origin from its exact URI/raw text and checked nonnegative i64 version (expected and actual), and downgrade its original open Arc in the same operation. Use existing index.native_open_buffer_input with explicit draft root/package/loader; validate all coordinates before draft.capture_sources exactly once. Propagate association String errors and Debug-rendered capture errors without partial success or synthesized inputs. Never accept a caller capture, lifetime or origin; index/plan/context and publisher authority remain with their owners.
`NativeOpenBufferSnapshot` is public in server.rs with private fields and only `captured(&self) -> &CapturedSnapshot`; no public constructor, Clone, conversion or mutation. It holds the original CapturedSnapshot clone, original URI/Weak relations and an owned release closure. Original native tuples/maps are shared through [Driver capture storage](../../mizar-driver/en/request.md#native-source-capture), never reloaded or reconstructed from an equal build id or Session lookup.
`Server::native_open_buffer_snapshot(&self) -> Option<Arc<NativeOpenBufferSnapshot>>` returns one complete immutable captured cohort only while initialized/live and every original URI/version/raw-text relation still matches and each original Weak::ptr_eq matches a freshly queried document_lifetime. It exposes source reads, no full artifact, pending work or cleanup authority; the borrowed ActiveBuild lease value transfers no ownership.

Server privately stores `Option<Arc<NativeOpenBufferSnapshot>>` without interior mutation. After acquiring a distinct real OpenBufferOverlay lease, successful capture atomically replaces that pointer; acquisition/capture failure leaves the old selection untouched. Replacement/invalidation requires an exclusive Server borrow; each originating consumer's immutable Server borrow prevents recapture during production and external Write, while owned reader Arcs remain usable across later edits/replacement. Accepted newer didChange (including empty/version-only changes) or didClose for any cohort URI clears it; ignored/invalid/stale/unrelated traffic preserves it. Shutdown/exit clear it without changing retained raw documents. Reopen cannot revive it. A reader keeps the entire original cohort/maps/overlay lease across replacement or invalidation; this retained source read is not stale_artifact or current delivery.
`NativeOpenBufferCapture` remains move-only with no public constructor/Clone/accessor/conversion. Privately it owns Option<BuildSession>, the association Arc and optional ActiveBuild cleanup closure. Drop releases that exact ActiveBuild lease only before handoff. Each originating consumer takes the original session and disarms cleanup immediately before its one existing Driver call; after handoff Driver retains its existing lease/deferred-retirement responsibility, including on errors.
If overlay allocation fails, release the never-handed-off ActiveBuild lease before returning String Err; validation failure before acquisition has no lease to release. Snapshot Drop releases exactly its own overlay lease once at the last association/reader/ticket reference. Each closure owns the actual registry Arc and exact lease; use invariant-specific expect messages on release errors rather than silently claiming cleanup. No Session production change or public lease wrapper is needed.
Both originating notification and writer operations select and hold the current association Arc across actual production/conversion/writing and require Arc::ptr_eq with the ticket's association for delivery. Preserve original incarnation, raw/native and Driver guards and the existing actual submission/error paths when ineligible. A newer capture suppresses an older ticket even for equal raw text/version/build id; retained reads grant no publication authority or IR publisher replacement.

## Freshness and replacement

Use the existing current/stale_artifact/pending meanings in [architecture12](../../architecture/en/12.diagnostics_and_lsp.md#open-buffers-override-disk-source). Current describes a response computed for the current editor source; it is not proof acceptance. Pending requires an actually scheduled/running verification. Missing producer inputs remain unavailable, rather than implying scheduled work or an empty successful snapshot.

Current syntax-only overlays may exist before full artifacts, but never supply semantic metadata or a coherent full LspSnapshot. On change/close/reopen, withhold old overlay delivery immediately; close removes its open association. Shutdown/exit allow no new current delivery. Do not relabel an old overlay by querying a new lifetime handle.

A retained artifact read may remain stale_artifact after an edit. Preserve its original source association and explicit stale status; suppress unsafe edits and current-buffer delivery whose target cannot be validated. Read-only stale ranges remain associated with their original retained source and explicit stale status; they are never relabeled as current-buffer ranges. Never clear diagnostics merely because producer work or a current map is absent. Task8 owns publication/conversion details; task10 owns scheduling/cancellation.

A full LspSnapshot requires the coherent completed build boundary and original manifest-backed metadata described by [internal03](../../internal/en/03.diagnostics_model_and_lsp_bridge.md#lsp-snapshot-publication). Read the manifest first, retain one complete immutable set, then atomically replace the handler-visible snapshot. ArtifactCommitted alone, Frontend completion and a diagnostic index do not establish that boundary. Driver's current event enum has no coherent SnapshotPublished producer; full snapshot construction/activation stays deferred until that owner supplies the genuine boundary and payloads.

## Currentness and retention

Keep [Driver lane/request publication](../../mizar-driver/en/request.md) separate from [IR publisher currentness](../../mizar-ir/en/publisher.md#snapshot-and-work-unit-validation). SnapshotHandleRegistry registers identity/lineage, not currentness. When build ids differ, an owner-authorized publisher replacement can obsolete the prior id. Equal-id editor edits still invalidate the editor association; do not call IR replace_current_snapshot with equal ids or revive an obsolete id.

Acquire and release LSP-owned Session leases through SnapshotRegistry with the actual PublishedLspSnapshot/OpenBufferOverlay retention reason. An ActiveBuild lease belongs to the captured build owner; cloning its value does not transfer cleanup authority. Retain only actual sealed IR outputs needed by a read using IrStorageService retain/release; a Session lease alone does not pin IR storage. Keep retention while a published/overlay association or any in-flight reader needs its data; release each owned retention only after both associations and readers are finished; collection may follow the upstream storage rules. Retention allows stale reading, never current publication or artifact authority.

## Implementation boundary

Task7 first implements only the retained native source association above. The full current/stale artifact registry, IR retention and coherent LspSnapshot remain separate; tasks8–11 bind diagnostics, scheduling and lifecycle cleanup. Do not create placeholder full snapshots, metadata indexes, manifests, event producers or runtime identities; this prerequisite does not complete task7, ENTRY/SCA-003 or Steps6–8.

## Test design

Use genuine accepted open/change/close/reopen/terminal messages and protected native capture. Check a version-only edit and a normalization-equivalent raw edit that share a build id, plus an identical-tuple reopen and another Server; each must suppress the old current association while preserving valid retained reads. A reader spanning replacement must observe one complete old/new association. Exercise actual Session lease and IR retain/release/collection separately, including stale-readable versus publisher-obsolete outputs and equal-id replacement refusal. Syntax-only success must not create full metadata/current-build completion; absent/partial producer work must not clear diagnostics or create pending work. Existing language, producer, mapper and lifecycle matrices remain unchanged.

For retained native sources, extend genuine originating-capture/notification/writer tests with independent raw/version/map facts: two equal-normalized-id captures, old reader across replacement, and native tuple/map pointer equality across Driver clone/submission. Cover identical-tuple reopen, cross-Server, closed/terminal suppression while old readers remain readable; failed capture preserves selection and ignored/invalid/unrelated traffic does not evict it.
Use a genuine observing Session allocator's lease IDs and actual release results to prove overlay retention while any stored association/reader/ticket remains, and exactly-once last-reference release. Prove never-handed-off ActiveBuild cleanup on ticket drop/overlay failure separately from Driver ownership after handoff. Preserve all existing assertions, native/raw-reopen/writer/error matrices and submission paths; permit mechanical registry-Arc/capture-mutability/private-field adaptations and resequence each existing discovery route to capture before deleting its native files, restoring only the fixture's invalid disk bytes between routes while preserving every unavailable-disk/current-delivery assertion. No fabricated producer, cache Hit/Accepted result, arbitrary timing or unsafe test access.
