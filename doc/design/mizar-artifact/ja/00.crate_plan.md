# Crate Plan: mizar-artifact

> 正本は英語です。英語版: [../en/00.crate_plan.md](../en/00.crate_plan.md)。

この計画は [todo.md](./todo.md) の `mizar-artifact` task 1-22 に対する
自律 crate 開発ワークフローの開始点である。この crate は安定した公開射影を
扱うインフラ crate であり、言語挙動 crate ではない。そのため、将来の task
が構文、静的意味論、証明意味論、診断、parser recovery、soundness boundary
を変更しない限り、test-first の `.miz` 追加は要求しない。

## 責務

所有する挙動:

- 公開 artifact 向けの正準 UTF-8 JSON シリアライゼーション、
  schema-version 互換性チェック、意味論/診断 hash の分離。
- 下流ツールと producer crate が消費する `ModuleSummary`、
  `RegistrationSummary`、`ProofWitnessRef`、`VerifiedArtifact` スキーマ。
- content-addressed artifact blob、temp-and-rename による named artifact の
  atomic write、読み込み時の破損/hash 検証。
- 決定的 entry 順序と old-or-new reader visibility を持つ package artifact
  manifest と manifest transaction。
- `mizar-cache` consumer 向けの interface-hash / implementation-hash 入力。

範囲外:

- compiler-internal cache record、cache-key trust decision、dependency-slice
  validation、cluster-db storage、proof-reuse policy（`mizar-cache`）。
- 射影入力を作る resolver/checker/VC/kernel/proof 出力
  （`mizar-resolve`、`mizar-checker`、`mizar-vc`、`mizar-kernel`、
  `mizar-proof`）。
- source identity、source map、build snapshot（`mizar-session`）。
- 言語構文、静的意味論、証明受理、診断、parser recovery の変更。

### Task MA-001: Crate scaffold and lint policy

Purpose: `mizar-session` のみを internal dependency とする `mizar-artifact`
workspace crate と lint-policy guard を追加する。

Completion condition:

- workspace が `mizar-artifact` を認識する。
- crate が workspace lints に opt in する。
- lint guard が dependency と public API policy を検査する。

Forbidden behavior:

- producer crates に依存すること。
- module spec なしで artifact 挙動を導入すること。

### Task MA-002: Store and canonical-form specification

Purpose: 正準 JSON、schema versions、hash separation、local metadata exclusion、
store layout、atomic writes を仕様化する。

Completion condition:

- 英語版と日本語版の仕様が存在し、同期している。

Forbidden behavior:

- store/canonical-form 挙動を文書化する前にコードを変更すること。

### Task MA-003: Canonical serialization and schema compatibility

Purpose: 共有の canonical JSON、hash helpers、schema-version checks を実装する。

Completion condition:

- 等価入力が byte-identical に serialize される。
- incompatible schema version が明確に失敗する。
- hash-excluded local fields が semantic hash に影響しない。

Forbidden behavior:

- malformed/partial JSON を valid artifact として受け入れること。
- timestamp、task id、temp name を semantic hash に含めること。

## Exit criteria

Hard gates:

- blocking/high specification contradiction が残らない。
- crate-owned infrastructure scope 内で design docs と Rust tests の外にある
  source behavior が残らない。
- task 1-16 と 18-22 が完了し、task 17 は `external_dependency_gap` として
  明示的に deferred である。
- 実装挙動に合わせるための `.miz` tests や既存 expectation files の変更を行わない。
- source と bilingual design docs が同期している。
- crate boundaries が producer crates、cache trust、proof acceptance を取り込まない。
- verification commands が通る、または未実行理由が明示される。

Verification commands:

```sh
cargo fmt --check
cargo clippy -p mizar-artifact --all-targets -- -D warnings
cargo test -p mizar-artifact
cargo clippy --all-targets --all-features -- -D warnings
cargo test
```

Review expectations:

- crate plan / specs 後の review-only specification/documentation review。
- tests 追加後の review-only test sufficiency review。
- 実装後の review-only implementation review。
- final verification 前の review-only source/documentation consistency と quality-score review。
