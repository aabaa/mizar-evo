\section{Part 2. Readable Mathematics}
\begin{frame}[fragile,t]{2.1 - type・registration・overload の追跡}
数学を自然に記述するため、処理系は多くの判断を自動的に行う。

\begin{itemize}
\setlength{\itemsep}{1pt}
\setlength{\parsep}{0pt}
\setlength{\parskip}{0pt}
\item \textcolor{blue!55!black}{\textbf{type: 対象をどの型として使えるか。}} 属性や継承をたどる。例: Group → Magma（継承経路が一意の場合）。
\item \textcolor{blue!55!black}{\textbf{registration: 必要な属性は、どの規則から得られたか。}} 例: empty → finite → countable という登録規則の連鎖。
\item \textcolor{blue!55!black}{\textbf{overload: どの定義を選び、どのビューで使うか。}} 同じ記号の候補や、環の加法・乗法のビューを区別する。
\end{itemize}
\textcolor{blue!55!black}{\textbf{自然な記述と自動適用を保ちながら、暗黙の判断の根拠を追跡可能にする。}}

\note{
\smallskip

\begin{itemize}
\setlength{\itemsep}{1pt}
\setlength{\parsep}{0pt}

\begin{frame}[fragile,t]{4.2 - Algorithm: 契約、証明、計算}
\smallskip
\textbf{\textcolor{blue!55!black}{\textbf{契約付きのユークリッドの互除法}}}~\badgeSpec
\begin{lstlisting}[language={mizar},basicstyle=\ttfamily\footnotesize]
terminating algorithm EuclidGcdDef: euclid_gcd(a, b) -> Nat
  requires a >= 1 & b >= 1
  ensures result = Gcd(a, b)
do
  var x := a;  var y := b;
  while y <> 0 do
    invariant x >= 1 & y >= 0 & Gcd(a, b) = Gcd(x, y);  decreasing y;
    const r := x mod y;  x := y;  y := r;
  end;
  return x;
end;
\end{lstlisting}

\begin{frame}[fragile,t]{4.3 - 互除法: コードと証明義務}
\smallskip
\textbf{互除法の本体を再掲（a,b >= 1、外枠省略）}~\badgeSketch
\begin{lstlisting}[language={mizar},basicstyle=\ttfamily\small]
var x := a; var y := b; :: (1)
while y <> 0 do
  invariant x >= 1 & y >= 0 & Gcd(a,b) = Gcd(x,y); :: (2)
  decreasing y; :: (3)
  const r := x mod y; x := y; y := r;
end;
return x; :: (4)
\end{lstlisting}
\par\noindent{\footnotesize\bfseries 表9　ユークリッドの互除法の証明義務\par}
\begin{footnotesize}

\begin{tabularx}{\textwidth}{ll>{\raggedright\arraybackslash}X}
\toprule
\textbf{箇所} & \textbf{証明義務} & \textbf{数学的な根拠} \\
\midrule
(1) & 不変条件の初期成立 & \texttt{x=a}, \texttt{y=b}。事前条件から正値性 \\
(2) & 不変条件の保存 & 旧 \texttt{(x,y)} から \texttt{(y,r)} へ。\texttt{Gcd(x,y) = Gcd(y,r)}、旧 \texttt{y >= 1}、\texttt{r >= 0} \\

\end{tabularx}
